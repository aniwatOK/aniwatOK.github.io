ข้อมูลโปรไฟล์

โปรไฟล์นี้เป็นการรวบรวมโปรเจกต์และผลงานต่างๆ ที่ผมได้ทำมาตลอดช่วงเวลาที่เรียนและฝึกงานในสายงานคอมพิวเตอร์และเทคโนโลยีสารสนเทศ

ผมได้พยายามสร้างผลงานที่หลากหลายทั้งในด้านการพัฒนาเว็บแอปพลิเคชัน การเขียนโปรแกรม และการจัดการ Deploy and Maintenance Web applications บน Cloud Platforms ของ DigitalOcean และพร้อมเรียนรู้ Google Cloud Platform / AWS เพื่อแสดงให้เห็นถึงความสามารถและความมุ่งมั่นในการเรียนรู้และพัฒนาตัวเองในสายงานที่หลากหลายในยุคสมัยปัจจุบันที่ความต้องการด้านเทคโนโลยีเพิ่มขึ้นอย่างรวดเร็ว

โปรไฟล์นี้จะช่วยให้ผู้ที่สนใจสามารถเข้าใจถึงประสบการณ์และทักษะที่ผมมี รวมถึงโปรเจกต์ที่ผมได้ทำมา แต่ทั้งหมดนี้ยังไม่ใช่ทั้งหมดเพราะผมพร้อมเรียนรู้สิ่งใหม่ๆตลอดเวลา หวังว่าจะเป็นประโยชน์ในการพิจารณาโอกาสในการทำงานหรือการร่วมงานในอนาคตครับ
